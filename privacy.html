Agent City is a personal tool used only by its owner to manage his own YouTube channels. This policy explains what data it accesses and how it is handled.

Data we access

With the owner's permission (Google sign-in), Agent City reads YouTube channel and video information for the owner's own channels: channel name, subscriber count, video titles and view/engagement statistics, through the YouTube Data API and YouTube Analytics API (read-only access).

How the data is used

The data is used only to show the owner how his channels and videos are performing and to help plan future videos. It is not sold, rented, shared with third parties, or used for advertising.

Where the data is stored

Data and sign-in tokens are stored only on the owner's own computer. Nothing is uploaded to a separate server operated by Agent City.

Google API Services

Agent City's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Agent City uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from your Google Account at myaccount.google.com/permissions. Disconnecting a channel in Agent City also deletes its stored token.
