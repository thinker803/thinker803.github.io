Agent City is a private, personal automation tool run by one person (the owner) on his own computer. It helps the owner plan and produce content for his own YouTube channels and keep track of how those channels are doing.

What it does with Google / YouTube

When the owner connects his own YouTube channels, Agent City reads basic channel and video statistics (such as subscriber counts, view counts and video titles) through the YouTube Data API and YouTube Analytics API, so the owner can see which videos perform best. It does not post, edit or delete anything on YouTube, and it is not offered to the public.

Agent City's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
